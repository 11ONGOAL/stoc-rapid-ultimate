# Deploy GitHub

1. Creează sau deschide repository-ul GitHub.
2. Încarcă toate fișierele și folderele din acest pachet direct în rădăcina repository-ului.
3. Fă commit pe branch-ul folosit de proiect (de regulă `main`).
4. Pentru Vercel: conectează/importă repository-ul în Vercel și fă deploy.
5. Pentru GitHub Pages: `Settings > Pages` → selectează branch-ul și `/ (root)`.

Important: păstrează folderul `assets/images` exact în această structură; acolo se află logo-ul și imaginile produselor.
